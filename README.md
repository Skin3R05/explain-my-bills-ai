Explain My Bills AI is an AI-driven utility bill analysis tool designed to help users understand and interpret their water, gas and electricity consumption. The application processes historical usage data, applies machine learning–based anomaly detection (Isolation Forest), and generates explanations for unusual billing patterns.

The system transforms raw utility data into structured insights, highlighting abnormal consumption and providing contextual reasoning behind detected anomalies. It is built with an interactive Streamlit dashboard that allows users to explore their data dynamically.

Key Features
Upload and process utility bill data (water, gas & electricity)
Detect anomalies using Isolation Forest
Generate human-readable explanations for charges
Analyze historical consumption patterns
Interactive Streamlit-based dashboard
Tech Stack

Python, Pandas, NumPy, Scikit-learn, Streamlit

Goal

The goal of this project is to make utility consumption data more transparent and understandable by combining machine learning with intuitive explanations.
